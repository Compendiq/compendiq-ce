<h1 align="center">Fastify</h1>

## Inhaltsverzeichnis der Guides
<a id="guides-toc"></a>

Dieses Inhaltsverzeichnis ist alphabetisch geordnet.

+ [Benchmarking](./Benchmarking.md): Dieser Guide führt ein, wie man
  Anwendungen auf Basis von Fastify benchmarkt.
+ [Contributing](./Contributing.md): Beschreibt im Detail, wie man sich an der
  Entwicklung von Fastify beteiligt, und zeigt, wie man eine Umgebung einrichtet,
  die mit dem Code-Stil des Projekts kompatibel ist.
+ [Delay Accepting Requests](./Delay-Accepting-Requests.md): Ein praxisnaher Guide
  dazu, wie man das Bedienen von Requests auf bestimmten Routen verzögert, bis in
  Ihrer Anwendung eine Bedingung erfüllt ist. Dieser Guide löst das Problem mit
  [`Hooks`](../Reference/Hooks.md), [`Decorators`](../Reference/Decorators.md)
  und [`Plugins`](../Reference/Plugins.md).
+ [Detecting When Clients Abort](./Detecting-When-Clients-Abort.md): Ein
  praxisnaher Guide zum Erkennen, ob und wann ein Client einen Request abbricht.
+ [Ecosystem](./Ecosystem.md): Listet alle Core-Plugins und viele bekannte
  Community-Plugins auf.
+ [Fluent Schema](./Fluent-Schema.md): Zeigt, wie JSON Schema mit einer
  Fluent-API geschrieben und in Fastify verwendet werden kann.
+ [Getting Started](./Getting-Started.md): Einführungstutorial für Fastify.
  Hier sollten Einsteiger beginnen.
+ [Migration Guide (v4)](./Migration-Guide-V4.md): Beschreibt im Detail, wie man
  von früheren Versionen auf Fastify v4 migriert.
+ [Migration Guide (v3)](./Migration-Guide-V3.md): Beschreibt im Detail, wie man
  von früheren Versionen auf Fastify v3 migriert.
+ [Plugins Guide](./Plugins-Guide.md): Eine informelle Einführung ins Schreiben
  von Fastify-Plugins.
+ [Prototype Poisoning](./Prototype-Poisoning.md): Eine Beschreibung, wie der
  Prototype-Poisoning-Angriff funktioniert und wie er entschärft wird.
+ [Recommendations](./Recommendations.md): Empfehlungen dazu, wie man Fastify in
  Produktionsumgebungen deployt.
+ [Serverless](./Serverless.md): Einzelheiten dazu, wie man Fastify-Anwendungen
  in verschiedenen Function-as-a-Service-Umgebungen (FaaS) deployt.
+ [Style Guide](./Style-Guide.md): Erläutert den Schreibstil, den wir für die
  Fastify-Dokumentation verwenden, für alle, die zur Dokumentation beitragen möchten.
+ [Testing](./Testing.md): Erläutert, wie man Unit-Tests für Fastify-Anwendungen
  schreibt.
+ [Write Plugin](./Write-Plugin.md): Eine Reihe von Richtlinien dazu, was das
  Fastify-Team als gute Praxis beim Schreiben eines Fastify-Plugins ansieht.
