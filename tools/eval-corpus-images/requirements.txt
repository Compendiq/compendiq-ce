# Transitive, and pinned for the same reason as Pillow rather than left to
# resolve: both of these decide what the page markdown says.
#
# `soupsieve` is the CSS-selector engine behind every `select()` in the builder
# — the DROP_SELECTORS sweep, the boxed-figure hoist and the figure
# collection — so a change in selector semantics silently changes which nodes
# are dropped, on the one tool whose entire contract is byte reproduction.
# 4.0 is also the first release outside all four published advisories
# (GHSA-mmhr-3c5m-f64f, GHSA-6655-6qjp-jx7x, GHSA-7g44-g9rc-x53w,
# GHSA-4j63-6c4x-wfg4); its selector cache must stay enabled (`NOCACHE` brings
# back the vulnerable descendant algorithm).
# `six` is markdownify's, and markdownify is the HTML -> Markdown converter.
soupsieve==4.0
six==1.17.0

# Deliberately NOT pinned: `certifi`, `urllib3`, `idna`, `charset-normalizer`
# and `typing_extensions`. They are requests' network and typing plumbing, they
# cannot reach the output bytes, and pinning `certifi` in particular freezes a
# CA bundle — a build tool that stops trusting Wikimedia's certificate is a
# worse failure than a floating transitive.
