# Transitive, and pinned for the same reason as Pillow rather than left to
# resolve: both of these decide what the page markdown says.
#
# `soupsieve` is the CSS-selector engine behind every `select()` in the builder
# — the 24-entry DROP_SELECTORS sweep, the boxed-figure hoist and the figure
# collection — so a change in selector semantics silently changes which nodes
# are dropped, on the one tool whose entire contract is byte reproduction.
# `six` is markdownify's, and markdownify is the HTML -> Markdown converter.
soupsieve==2.9.2
six==1.17.0
